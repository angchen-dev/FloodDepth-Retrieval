# FLOOD-DEPTH-ML paper baseline

This directory contains the complete FLOOD-DEPTH-ML code used for the paper
comparison.

- `flooddepthml.py`: original application and inference implementation.
- `main_floodify_compare.ipynb`: paper evaluation workflow.
- `requirements.txt`: original dependency list.

Weights, media, and saved predictions are stored in
`data/baselines/flood_depth_ml/`. The original paths are preserved at this
migration stage and will be converted to public CLI arguments separately.
