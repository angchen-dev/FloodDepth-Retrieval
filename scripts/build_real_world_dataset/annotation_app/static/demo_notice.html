Flood-Depth Annotation Demo

Demo Notice

Purpose of This Demo

This interface demonstrates the annotation application used in the study Flood depth estimation using images of vehicles: a new image retrieval framework with annotated datasets to collect annotated flood depths for the real-world dataset. This public version is provided for software demonstration and reproducibility purposes only. It is not configured for participant recruitment or new research data collection.

What the Demo Involves

You will first see three trial images and then five annotation images. For each image, select a similar 3D vehicle and align the virtual water plane with the visible flood waterline. The demo should take approximately 5–10 minutes.

Local Demo Data
  • Use a non-identifying Demo ID. Do not enter your name, email address, or other personal information.
  • Demo entries are stored only in the local SQLite database of the machine running this application.
  • Delete the local database when the demonstration records are no longer needed.
Before Collecting Research Data

Before using this application with research participants, replace this notice with an institutionally approved participant information and consent form. The replacement must identify the responsible organisation and researcher, provide valid contact and ethics information, and explain data processing, retention, sharing, withdrawal, and participant rights.
